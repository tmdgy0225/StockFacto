# ADR-0001: 검증 노드는 Non-AI(결정론적)로만 구성한다

- 상태: 채택 (2026-10-10)

## 맥락
LLM 이 생성한 매매 코드는 손절선 누락·비중 초과·가짜 뉴스 기반 판단 같은 위험을 포함할 수 있다.
검증까지 LLM 에 맡기면 검증 결과도 확률적이 되어 "100% 차단"을 주장할 수 없다.

## 결정
- 팩트 검증(DART 대조), 비중 상한 결정, Lint, Sandbox, Quality Gate 는 모두 규칙 기반 코드로 구현한다.
- LLM 은 Plan 이 정한 제약 안에서 매매 로직을 작성하는 역할만 맡는다 (블루프린트 아키텍처).
- 리스크 파라미터는 LLM 이 정하지 않고 하네스가 `ctx.max_weight` 로 주입한다.
- 정적 분석으로 판단할 수 없는 값은 런타임(sandbox_runner)에서 다시 집행하며, 판단 불가 시 차단한다(fail-closed).

## 결과
- 같은 입력에 같은 판정 → A/B 평가 재현 가능.
- 의미적 오류(전략 논리가 이상함)는 잡지 못한다 → 추론적 센서(LLM 리뷰어)는 보조 경고용으로만 고려 (features.json F-20).
