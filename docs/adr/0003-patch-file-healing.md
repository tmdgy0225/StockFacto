# ADR-0003: Self-Healing 재시도는 patch_file(부분 수정)으로 한다

- 상태: 채택 (2026-10-13)

## 맥락
초기 Self-Healing 은 실패할 때마다 에이전트가 코드 전체를 다시 출력했다.
한 줄짜리 수정(손절선 추가)에도 전체를 다시 쓰므로 출력 토큰이 낭비되고, 고친 곳 외의 코드가 의도치 않게 바뀔 수 있다.
강의 자료(patch_file 도구)와 기획서 4단계("patch_file 생성")도 부분 수정을 요구한다.

## 결정
- 재시도에서는 직전 코드를 줄 번호와 함께 보여주고, 에이전트는 `{"patches": [...]}` (replace/insert/delete) 만 출력한다.
- 패치 적용은 하네스가 결정론적으로 한다(`harness/patch.py`). 범위 초과·겹침·형식 오류는 적용하지 않고 R-008 로 되돌린다(fail-closed).
- 에이전트가 패치 대신 전체 코드를 내면 `rewrite` 로 기록하고 그대로 검증한다(호환성).

## 결과
- Mock 기준 재시도 출력 토큰 65% 절감, 20개 케이스 최종 결과 동일 (`python -m harness.eval --compare-healing`).
- 실제 LLM 은 줄 번호를 틀릴 수 있다 → R-008 비율을 Claude 실측(F-18)에서 확인해야 한다.
